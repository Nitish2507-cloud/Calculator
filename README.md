# Smart Calculator Pro X

A modern and responsive calculator web application built using HTML, CSS, and JavaScript. The project combines a futuristic user interface with advanced calculator functionality, providing a professional and interactive user experience.

## Features

* Basic Arithmetic Operations

  * Addition
  * Subtraction
  * Multiplication
  * Division

* Real-Time Result Preview

* Scientific Functions

  * Square Root (√)
  * Square (x²)
  * Sine (sin)
  * Cosine (cos)
  * Tangent (tan)

* Calculation History

* Export History to Text File

* Copy Result Functionality

* Keyboard Support

* Theme Switching (Classic & Cyber Mode)

* Local Storage Persistence

* Responsive Design

* Animated Loading Screen

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Nitish2507-cloud/Calculator.git
```

2. Open the project folder.

3. Launch `index.html` using:

   * VS Code Live Server, or
   * Any local web server.
